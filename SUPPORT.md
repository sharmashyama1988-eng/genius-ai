# Getting Support with Genius AI

Thank you for using **Genius AI**! This document explains the best channels to receive help, ask questions, and report issues.

---

## Where to Get Help

### 1. Documentation & Architecture
- **[README.md](README.md)**: Quickstart guide, installation commands, architecture overview, and benchmark summary.
- **[SPECIFICATION.md](SPECIFICATION.md)**: Comprehensive 7-node Cognitive State Graph v2.0 and xThinking Engine technical specification.
- **[COMMANDS.md](COMMANDS.md)**: Complete list of all CLI slash commands (`/agent`, `/skills`, `/search`, `/stats`, etc.).

### 2. GitHub Discussions
For general questions, architecture ideas, model recommendations, and troubleshooting tips:
- Visit **[GitHub Discussions](https://github.com/sharmashyama1988-eng/genius-ai/discussions)**
- Share custom skill templates or community prompts.

### 3. Reporting Bugs
If you found a reproducible bug or unexpected error:
- Search existing [GitHub Issues](https://github.com/sharmashyama1988-eng/genius-ai/issues) to see if it has already been reported.
- If not, submit a new issue using our [Bug Report Form](.github/ISSUE_TEMPLATE/bug_report.yml).

### 4. Feature Requests & Proposals
Have an idea to make Genius AI even faster or more powerful?
- Submit a request using our [Feature Request Form](.github/ISSUE_TEMPLATE/feature_request.yml).
- Before starting significant development, open an issue or RFC discussion so maintainers can provide feedback on alignment with CSG v2.0 invariants.
