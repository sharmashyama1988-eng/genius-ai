# 💻 Coding & Architecture Guidelines

## Software Engineering Standards
- **Zero Placeholders**: Never write `// TODO: Implement later` or `pass # user implementation`. Always supply complete, working implementations.
- **Type Safety**: Use explicit type annotations (Python typing, TypeScript, Rust, Go types) wherever possible.
- **Defensive Programming**: Validate inputs, handle edge cases (nulls, empty inputs, network timeouts, divide-by-zero), and provide clean error messages.
- **Modern Paradigms**: Prefer idiomatic code: list comprehensions, context managers (`with`), async/await where I/O bound, and clean modular class structures.
