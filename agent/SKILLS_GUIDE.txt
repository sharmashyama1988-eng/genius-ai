3. HOW TO WRITE A SKILL MANUALLY (User Khud Script Kaise Likhe?)
--------------------------------------------------------------------------------
Skill likhne ke sirf 3 basic rules hain (Zero Complexity):

RULE 1: File ke top par Docstring likho
  AI docstring padh kar samajhta hai ki yeh tool kab aur kyu chalana hai.

RULE 2: Main logic ko ek function mein wrap karo
  Jaise: def generate_data(...), def convert_file(...), def fetch_prices(...)

RULE 3: CLI Entrypoint do (`if __name__ == "__main__":`)
  Taaki AI aur User terminal se bhi direct command chala sakein.

────────────────────────────────────────────────────────────────────────────────
TEMPLATE (Copy & Paste this to create any new skill):
────────────────────────────────────────────────────────────────────────────────
"""
My Custom Skill Name — One line summary of what this tool does.

Detailed Description:
  • Does X, Y, and Z
  • Takes inputs: A, B
  • Returns output file or result
"""

from __future__ import annotations
import argparse
import sys
from pathlib import Path

def my_main_function(input_data: str, output_path: str = "result.txt") -> str:
    """Core logic of your tool."""
    out_p = Path(output_path).resolve()
    
    # ── YOUR CODE GOES HERE ──────────────────────────────────
    processed = f"Processed: {input_data.upper()}"
    out_p.write_text(processed, encoding="utf-8")
    # ─────────────────────────────────────────────────────────
    
    return str(out_p)

def main():
    parser = argparse.ArgumentParser(description="My Custom Skill CLI")
    parser.add_argument("-i", "--input", required=True, help="Input argument")
    parser.add_argument("-o", "--output", default="output.txt", help="Output path")
    args = parser.parse_args()

    try:
        res = my_main_function(args.input, args.output)
        print(f"SUCCESS: Saved output to {res}")
    except Exception as e:
        print(f"ERROR: {e}", file=sys.stderr)
        sys.exit(1)

if __name__ == "__main__":
    main()
